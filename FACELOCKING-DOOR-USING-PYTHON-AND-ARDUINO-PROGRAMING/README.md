# 🔐 Face Recognition-Based Smart Door Lock System

A simple and effective smart door lock system using **Python** for face recognition and **Arduino UNO** for controlling a **servo motor**. This project helps authenticate users using their face and unlocks the door automatically if the face matches.

---

## 🛠 Tech Stack

- Python (OpenCV, face recognition, serial)
- Arduino UNO
- Servo Motor
- USB Cable
